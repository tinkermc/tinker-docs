# FAQ

Can't find your answer? Ask us on [Discord](/help/support).

## What do I need to run Tinker?

A Windows PC for Tinker Dash, and a Linux machine for Tinker Agent. An old PC works great. The Agent installs Java for you. See [Requirements](/getting-started/requirements).

## What's the difference between Dash and Agent?

Tinker Dash is the app on your PC where you click, browse and manage. Tinker Agent is a small program on your server PC that actually runs your Minecraft servers. Dash sends instructions and the Agent does the work. See [How Tinker works](/getting-started/how-it-works).

## Can Dash and the Agent run on the same computer?

Yes. One computer can run the Agent, Dash, and play on the server at the same time.

## Which server types are supported?

Vanilla, Paper, Fabric and NeoForge.

## How many servers can I run?

As many as your server PC can handle. One Agent can run many servers, and there's no limit on the free plan.

## How is this different from other server panels?

Tinker is a desktop app, not a web panel you host and secure yourself. You get the console, players, world tools and server setup in one place, without touching the command line.

## Is Tinker free?

Yes. Tinker Dash and Tinker Agent are free. Tinker Plus is an optional $4.99/month upgrade with extras like the [Connection Tunnel](/remote/tinkertunnel) and cloud backups. If you cancel Plus, your servers keep working on the free plan.

## Can I move my servers from Crafty Controller?

Yes. The Agent finds Crafty's servers automatically, or you can point it at any folder. It copies the server in and leaves the original untouched. Stop the server in Crafty first. See [Import from Crafty](/dash/import-crafty).

## How do I manage my server when I'm away from home?

Use [Tailscale](/remote/tailscale) for free, or turn on the [Connection Tunnel](/remote/tinkertunnel) with Tinker Plus. Never open the Agent's port (`7122`) to the internet.

## Will I lose my world if the server PC shuts down?

Tinker always saves before stopping, including when the server PC shuts down normally. A sudden power cut can still lose recent changes, so keep backups.

## Are you affiliated with Mojang or Microsoft?

No. Tinker is an independent project and isn't affiliated with or endorsed by Mojang or Microsoft.
