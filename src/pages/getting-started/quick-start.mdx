# Quick start

Go from a fresh setup to a running Minecraft server in three steps.

::::steps
##### Install Tinker Agent
Choose the Linux computer that will host your server, then follow [Install the Agent](/agent/install). Save the address, port, and private token that the setup prints.

##### Connect Tinker Dash
Install Dash on your Windows PC and enter the Agent details in the Connection screen. Follow [Connect to your Agent](/dash/connect) if you need help.

##### Create and start a server
Create a server from Dash, choose its type and version, and accept the Minecraft EULA only after reading it. When setup finishes, select the server and press **Start**. See [Create a server](/dash/create-server) for details.
::::

Keep the Agent PC on while you play. If Dash cannot connect, check [Agent troubleshooting](/agent/troubleshooting). For what each part does, read [How Tinker works](/getting-started/how-it-works).
