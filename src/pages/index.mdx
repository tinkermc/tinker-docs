# Welcome to Tinker

Tinker helps you run and manage a Minecraft server on a computer you control. **Tinker Agent** runs beside your server files, while **Tinker Dash** is the desktop app you use to start servers, read the console, and manage players.

## Get started

1. Check that your computers meet the [requirements](/getting-started/requirements).
2. Follow the [quick start](/getting-started/quick-start) to install the Agent and connect Dash.
3. Learn [how Dash and Agent work together](/getting-started/how-it-works).

Tinker is in beta. Some screens and features may change between releases. For help, visit [Support](/help/support).
