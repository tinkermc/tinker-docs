# Create a server

Create a server from the **Servers** area in Tinker Dash. Your Agent PC needs an internet connection while it downloads the server software.

1. Choose **Create server**.
2. Choose an available server type, such as Vanilla, Paper, or Fabric.
3. Select a Minecraft version supported by your current build.
4. Enter a name that helps you recognize this server. If the form asks for a port, choose one not already used by another server.
5. Review and accept the Minecraft EULA only if you agree to its terms. You can read it at [minecraft.net/eula](https://www.minecraft.net/eula).
6. Start the creation process and wait for the Agent to download and configure the files.

When setup finishes, select the new server and choose **Start**. The first start may take longer than later starts. Keep the Agent PC running while it downloads; do not close Dash to cancel a task unless you intend to stop it.

If setup fails, check the Agent connection and internet access, then ask for help with the error details in [Support](/help/support). Never share your Agent token in a screenshot.
