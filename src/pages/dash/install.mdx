# Install Tinker Dash

Tinker Dash is a Windows desktop app. During the beta, download the installer from the official Tinker beta channel in [Discord](https://discord.gg/9G9H4HdtJx). Do not use an installer from an unofficial download site.

## Install on Windows

1. Download the current Tinker Dash installer from the beta channel.
2. Open the downloaded installer and follow the Windows prompts.
3. Start Tinker Dash from the Start menu or the shortcut created by the installer.
4. Continue to [Connect to your Agent](/dash/connect).

Windows may show a security warning for a beta app that is not widely recognized yet. Before continuing, make sure the installer came from the official Tinker channel and that the publisher and file name match the release notes. If you cannot verify the source, cancel the install and ask in [Support](/help/support); do not bypass a warning for an unknown file.

To update Dash, download and install the newer official beta release. Updating Dash is separate from [updating the Agent](/agent/update).
